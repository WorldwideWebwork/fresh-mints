# MVP Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Demo each of the three partner asks end to end at http://mycompass/fresh-mints: website outreach (practice preview working), the review-and-send queue reaching Reddit, and a newly-licensed insurance producer source.

**Architecture:** Three thin slices. Slice A repairs a reactivity defect in the practice-website preview. Slice B adds one server-side Reddit fetch route to the plugin (the browser cannot reach Reddit: CORS) and gives social rules a per-rule reply template and funnel link, with an education-only annuity preset. Slice C finds a real machine-readable insurance-producer licence source and adds it as a registry tier. The full server-side Social Radar plan stays deferred; Slice B builds the first piece of it under the names that plan uses, so nothing is thrown away.

**Tech Stack:** Svelte 5 runes, TypeScript, Vitest, Vite; PHP WordPress plugin with `wp_remote_get`; WordPress in Docker (`u-wordpress`) with wp-cli.

**Spec:** Slice B is a subset of `docs/architecture/arch-social-radar-server-side.md` in the parent repo's `docs` submodule (sections 3, 6, 9, 10, 13). Slices A and C have no separate spec; this plan is their design, approved by the owner on 2026-10-09.

## Global Constraints

- **Repos and branches:** client work in `apps/fresh-mints` (origin `WorldwideWebwork/Fresh-Mints`), plugin work in `wp-content/plugins/xophz-compass-fresh-mints` (origin `HalloftheGods/xophz-compass-fresh-mints`). Both on `chem-x/mvp-demo`. Never commit on `main`.
- **Live environment:** the app runs at `http://mycompass/fresh-mints` inside the `u-wordpress` container, which mounts this repo's `wp-content` read-write. Plugin PHP changes take effect immediately. Client changes appear there only after `pnpm build` (output goes to the plugin's `public/dist`). Implementers MAY build to verify but MUST NOT commit `public/dist`; Task 7 commits the final bundle once.
- **Exercising permission-gated routes:** use wp-cli as admin, never a password: `docker exec u-wordpress wp --allow-root eval '<php>'`, with `wp_set_current_user(1)` and `rest_do_request()`. The container prints unrelated PHP deprecation notices from other plugins; ignore them.
- **Gate baseline:** `pnpm check` reports **24 errors, 24 warnings** on main (`52add15`). No task may raise it. Task 1 should lower it to 10.
- **Tests:** run via chemx (`chemx({action:"test", params:{dir, command:"pnpm exec vitest run"}})`). Never `pnpm test` (watch mode). Suite is 165 passing on main. `vitest.config.ts` has no Svelte plugin: test pure `.ts` modules, not `.svelte` files.
- **Tooling hook:** a pre-tool hook routes source reads, greps and test runs through `chemx`. chemx has no `log` action and its `typecheck` action reports `errorCount: 0` even when failing. Where chemx cannot do the job, append `# chemx-bypass: <reason>` to the bash command.
- **No PHP test harness exists.** PHP is verified by real wp-cli calls with pasted output, not PHPUnit (adding PHPUnit is Social Radar plan Task 1, out of scope).
- **Zero synthetic data (AGENTS.md 2.D):** never invent a value for a missing field. Render or store it empty, or skip the record.
- **No em dashes anywhere (AGENTS.md 7.B).** Organisms contain no raw DOM (1.H). No nested ternaries in templates (3.D). Validate external payloads before use (2.F).
- **Commit trailer:** every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Reddit stays disabled by default.** Owner decision 2026-10-07: Reddit's free tier excludes commercial use, so the provider ships behind option `xophz_compass_freshmints_social_reddit_enabled`, default `'0'`. Turn it on only to verify, and turn it back off.

## Review Focus

1. **Reddit refusing the server.** A 403 or 429 from Reddit must surface as `failed` with the real HTTP status, never as `ok` with zero posts. Task 2.
2. **A rule with no target channels.** Must fall back to a sensible default subreddit set, never request `r//search.json`. Task 2.
3. **A lead with no city and/or no state in the practice preview.** No dangling `", "` or `"()"` in the rendered copy. Task 1.
4. **Rules saved in localStorage before the new optional fields existed.** They must load and behave exactly like today's website rules. Task 4.
5. **Producer rows missing a licence number or issue date.** Skipped or left empty, never invented. Task 6.

### Task 2: Server-side Reddit fetch route

**Files:**
- Create: `includes/social/providers/class-freshmints-social-provider-reddit.php` (the path the deferred Social Radar plan uses, so its Task 5 extends this file rather than moving it), `includes/social/class-freshmints-social-rest.php`
- Modify: `xophz-compass-fresh-mints.php` (`require_once` both; register `Freshmints_Social_Rest` inside the existing `rest_api_init` closure at line 40 beside `new Freshmints_API()`)

**Interfaces:**
- Produces: `Freshmints_Social_Provider_Reddit::fetch_posts( array $rule ): array` returning exactly one of `[ 'status' => 'ok', 'posts' => array ]`, `[ 'status' => 'blocked', 'reason' => string ]`, `[ 'status' => 'failed', 'reason' => string ]`, where each post has the keys of the client's `RawSocialPost` (`id`, `platform`, `externalId`, `author`, `title`, `content`, `url`, `timestamp`, `score`, `commentsCount`, `subredditOrChannel`).
- Produces: `POST /wp-json/xophz-freshmints/v1/social/fetch`, body `{ platform: 'reddit', keywords: string[], targetChannels: string[] }`, response is the outcome above. Permission: `current_user_can( 'manage_options' )`, matching `Freshmints_API::check_permissions`.

Endpoint: `https://www.reddit.com/r/<channels joined by +>/search.json?q=<keywords joined by " OR ", urlencoded>&sort=new&restrict_sr=on&limit=15`. Default channels when none given: `smallbusiness+entrepreneur+webdev+sales` (today's client default). Header `User-Agent: xophz-compass-fresh-mints/<XOPHZ_COMPASS_FRESHMINTS_VERSION> (+<home_url()>)`. `wp_remote_get`, timeout 10s. A `WP_Error` becomes `blocked`; non-200 becomes `failed` with the status; a non-JSON or malformed body becomes `failed`. Empty keywords returns `ok` with no posts and makes no request. When the enable option is not `'1'`, return `failed` with reason `Reddit is disabled pending commercial API terms.` and make no request. Secrets never appear in any reason string.

- [ ] **Step 1:** Implement both classes and wire them in.
- [ ] **Step 2:** Verify with wp-cli as admin, pasting real output: (a) option off returns the disabled `failed`; (b) option on with `keywords:["need website"]` returns `ok` with posts, or `failed` carrying Reddit's real status if it refuses the container; (c) empty keywords returns `ok` with zero posts; (d) `targetChannels: []` requests the default channels. Set the option back to `'0'` and show it.
- [ ] **Step 3:** Commit in the plugin repo.
